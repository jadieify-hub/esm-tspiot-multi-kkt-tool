# v11

## Что изменилось

- Главная форма разделена на вкладки `Вторая ККТ`, `ККТ в ЕСМ`, `Автоматический режим` и `Журнал`.
- Добавлены верхнее меню, постоянная строка подключения и строка состояния.
- Добавлена таблица экземпляров ЕСМ с явной защитой первой ККТ.
- Добавлено безопасное удаление дополнительного экземпляра через `DELETE /api/v1/tspiot/{id}`.
- Удаление требует последние четыре цифры серийного номера, повторно проверяет список перед запросом и подтверждает результат повторными `GET`.
- При неоднозначном определении первой ККТ удаление блокируется для всех строк.
- Инструкция для начинающих обновлена для трех сценариев и нового интерфейса.

## Варианты сборки

- `legacy-win7-11-anycpu` - компактный EXE для .NET Framework 4.8.
- `modern-win10-11-x64` - автономный EXE для Windows x64.
- `modern-win10-11-x86` - автономный EXE для Windows x86.

Legacy-сборка предназначена для Windows 7 SP1 и новее. В текущем цикле все три файла фактически запущены и визуально проверены на Windows 11; отдельная виртуальная машина Windows 7 не использовалась.
