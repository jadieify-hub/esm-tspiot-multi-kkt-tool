# v11

## Что изменилось

- Главная форма разделена на вкладки `Ручное подключение`, `ККТ в ЕСМ`, `Автоматический режим` и `Журнал`.
- Добавлены верхнее меню, постоянная строка подключения и строка состояния.
- Добавлена таблица экземпляров ЕСМ с явной защитой первой ККТ.
- Добавлено безопасное удаление дополнительного экземпляра через `DELETE /api/v1/tspiot/{id}`.
- Удаление требует последние четыре цифры серийного номера, повторно проверяет список перед запросом и подтверждает результат повторными `GET`.
- При неоднозначном определении первой ККТ удаление блокируется для всех строк.
- Инструкция для начинающих обновлена для трех сценариев и нового интерфейса.
- Ручная вкладка поддерживает последовательное подключение третьей, четвертой и следующих ККТ с показом занятых портов и безопасным подбором свободной пары.
- В метаданные сборок и окно «О программе» добавлены издатель/владелец KRS и автор Руслан Керусов.

## Стандартная сборка

- `MultiKKT-ESM-TSPioT-v11.exe` - компактный AnyCPU EXE для .NET Framework 4.8 и Windows 7 SP1-11.

Автономные Modern-сборки размером около 60 МБ не публикуются по умолчанию и собираются отдельно только по запросу. Компактный файл фактически запущен и визуально проверен на Windows 11; отдельная виртуальная машина Windows 7 не использовалась.
