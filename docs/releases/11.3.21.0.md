# 11.3.21.0 — сервер ЛМ ЧЗ, ЛМ на другом компьютере, контроллер без подписи

- Новое: меню `ККТ → Сервер ЛМ ЧЗ...` ставит на выделенный компьютер до 32 ЛМ ЧЗ по номерам (API `5995`, `6995`, `7995`…), без ЕСМ, ККТ и ИНН. Окно показывает адреса для касс и копирует их; уменьшение числа снимает лишние ЛМ с конца. Правило брандмауэра ЛМ сервера действует во всех профилях сети, включая общедоступную; правила ЛМ на кассах не меняются.
- Новое: меню `ККТ → ЛМ ЧЗ на другом компьютере...` задаёт для ИНН адрес `адрес:порт` ЛМ на сервере. Для такого ИНН ЛМ на кассу не ставится, контроллер ККТ направляется на сервер; если все ЛМ удалённые, MSI ЛМ не нужен. У штатного `esm-lm-controller` в вендорском `config.yml` меняются только `lmConfig.url` и `lmConfig.port`, прежние значения возвращаются при удалении или возврате к локальному ЛМ.
- Исправлено: неподписанный `lmcontroller.exe` отклонялся с сообщением «не подписан», и контроллеры не настраивались. Подпись контроллера больше не требуется: он принимается по установленному продукту «ЕСП Контроллер ЛМ ЧЗ» и файлу в его каталоге. Подпись MSI ЛМ ЧЗ по-прежнему обязательна.
- Журнал: при незавершённом откате установки ЛМ сохраняется исходная причина ошибки; сообщение о чужой паре служб ЛМ называет фактический и ожидаемый путь запуска каждой службы.
- Проверено: полная матрица сборки и тестов; установка трёх ЛМ окном «Сервер ЛМ ЧЗ» на реальной машине. Обращение касс к серверу по сети, правка настоящего вендорского `config.yml` и работа неподписанного контроллера на физической кассе в рамках выпуска не проверялись.

## Установка и ограничения

Нужны Windows, .NET Framework 4.8, права администратора, штатные ЕСМ/ТС ПИоТ и Драйвер ККТ АТОЛ v.10. Для обычного режима нужен установленный `ЕСП Контроллер ЛМ ЧЗ` любой сборки; официальный MSI ЛМ ЧЗ оператор выбирает отдельно. Для сервера ЛМ ЧЗ нужен только MSI ЛМ ЧЗ.

Скачайте `MultiKKT-ESM-TSPioT-11.3.21.0.zip` и `SHA256SUMS-MultiKKT-11.3.21.0.txt`, проверьте SHA-256 и распакуйте ZIP целиком в новую папку. Не смешивайте EXE, DLL и `Provisioner` разных версий.

API ЛМ ЧЗ работает по HTTP без шифрования: открывайте сервер только во внутренней сети или через VPN, не в интернет. Бизнес-инициализация каждого ЛМ на сервере выполняется отдельно.

В поставке нет Firebird, FMU-API, вендорных MSI, `lmcontroller.exe`, отдельного Erlang runtime или данных клиента. Бизнес-инициализация ЛМ и проверка кассового ПО выполняются отдельно. Перед изменением Frontol нужна штатная резервная копия базы; меняются только адрес и порт ЕСМ.

Полевой чек-лист остаётся планом проверки: непройденные испытания текущего выпуска не объявляются успешными.
