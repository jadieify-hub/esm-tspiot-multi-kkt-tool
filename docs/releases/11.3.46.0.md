# MultiKKT 11.3.46.0

- **Инициализация ЛМ ЧЗ из MultiKKT.** Откройте «Обзор касс», выберите зарегистрированную ККТ и нажмите «Инициализировать ЛМ ЧЗ…». Параметры контроллера программа берёт из ЕСМ. В полевой проверке ЕСМ сообщил, что инициализация уже идёт. Готовность ЛМ можно проверить кнопкой «Диагностика выбранной ККТ». Первый запуск до состояния Ready остаётся отдельной полевой проверкой.
- **Регистрация касс.** MultiKKT сверяет заводской номер, ФН и ИНН с регистрацией в ЕСМ. При расхождении мастер указывает поле и позволяет продолжить работу с остальными кассами. При потере ответа на запись программа запрашивает состояние экземпляра.
- **Обзор касс.** Для выбранной строки видны адрес ЛМ, контроллер для ЕСМ и последний результат проверки. При смене строки предыдущий подробный отчёт скрывается.
- **Служебные операции.** Перед массовой настройкой видны кассы и количество ИНН. При отмене выбора другого установщика или ошибке его проверки сохраняется прежний MSI. Запрос записи учётных данных контроллера отклоняет HTTP-перенаправление.

Для обновления распакуйте ZIP целиком в отдельную папку и запустите MultiKKT. Требуются Windows 10/11 и .NET Framework 4.8.
