# MultiKKT 11.3.49.0

- После команды «Инициализировать ЛМ ЧЗ» оставьте MultiKKT открытым. Программа проверяет состояние выбранной ККТ каждые 15 секунд. Когда ЕСМ сообщит Ready, результат появится в обзоре и журнале, а опрос завершится. При ответе ЕСМ 2073 программа покажет «Инициализация уже идёт» и продолжит наблюдение.
- При открытии и обновлении «Обзора касс» индикатор в шапке отражает связь с ЕСМ. Пустой список касс тоже подтверждает доступность сервиса.
- В диагностике ЛМ видны версия, адрес и состояние из ЕСМ. При расхождении адресов рядом показан адрес из настроек MultiKKT. В журнале установки для каждого ИНН указан результат. Во время длительных операций время ожидания обновляется на экране.

Для обновления распакуйте ZIP целиком в отдельную папку и запустите MultiKKT. Требуются Windows 10/11 и .NET Framework 4.8.
