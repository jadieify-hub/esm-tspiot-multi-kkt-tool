# 11.3.23.0 — ЛМ ЧЗ из Program Files (x86), ожидание запуска ЛМ до 5 минут

- Исправлено: ЛМ ЧЗ, установленный вручную, отклонялся с ошибкой «Local-module service pair is foreign». Пакет ЛМ 32-битный, и на 64-битной Windows он ставится в `C:\Program Files (x86)\Regime`, а программа ждала базовый ЛМ только в `C:\Program Files\Regime`. Теперь уже установленный базовый ЛМ принимается там, где он есть, без переустановки и без изменения его инициализации. ЛМ, который ставит сама программа, по-прежнему идёт в `Program Files\Regime`.
- Исправлено: на кассе ЛМ ЧЗ запускается до нескольких минут, а программа ждала его порт 45 секунд и откатывала свежую установку. Ожидание увеличено до 5 минут; при тайм-ауте сообщение называет срок.
- Проверено: полная матрица сборки и тестов. Приём ЛМ из `Program Files (x86)` и долгий запуск ЛМ на физической кассе в рамках выпуска не проверялись.

## Установка и ограничения

Нужны Windows, .NET Framework 4.8, права администратора, штатные ЕСМ/ТС ПИоТ и Драйвер ККТ АТОЛ v.10. Для обычного режима нужен установленный `ЕСП Контроллер ЛМ ЧЗ` любой сборки; официальный MSI ЛМ ЧЗ оператор выбирает отдельно. После установки .NET Framework 4.8 перезагрузите компьютер, иначе ЛМ ЧЗ не установится.

Скачайте `MultiKKT-ESM-TSPioT-11.3.23.0.zip` и `SHA256SUMS-MultiKKT-11.3.23.0.txt`, проверьте SHA-256 и распакуйте ZIP целиком в новую папку. Не смешивайте EXE, DLL и `Provisioner` разных версий.

API ЛМ ЧЗ работает по HTTP без шифрования: открывайте сервер ЛМ ЧЗ только во внутренней сети или через VPN, не в интернет.

В поставке нет Firebird, FMU-API, вендорных MSI, `lmcontroller.exe`, отдельного Erlang runtime или данных клиента. Бизнес-инициализация ЛМ и проверка кассового ПО выполняются отдельно.

Полевой чек-лист остаётся планом проверки: непройденные испытания текущего выпуска не объявляются успешными.
