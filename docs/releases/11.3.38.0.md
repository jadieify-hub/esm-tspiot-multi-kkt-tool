# MultiKKT 11.3.38.0

Стабильный выпуск для Windows 10/11 и .NET Framework 4.8. С версии 11.3.26.0 изменился порядок работы с кассами и локальными модулями «Честного знака».

## Что изменилось

- **Регистрация ККТ.** Во вкладке «Настройка ККТ» кнопка «Найти и зарегистрировать кассы» запускает автоматическую регистрацию. В режиме «По одной кассе» сначала выполняется поиск, затем оператор выбирает кассу по заводскому номеру и подтверждает регистрацию. Настройку ЛМ можно выполнить следующим шагом или отложить.
- **Размещение ЛМ.** Мастер показывает выбранную кассу и поля адреса и порта удалённого ЛМ над списком. Ошибка отмечается рядом с соответствующим полем. Перед новой локальной установкой можно проверить название, версию и полный путь официального MSI, выбрать другой файл или отменить установку.
- **Обзор касс.** Название организации берётся из регистрационных данных ККТ через драйвер АТОЛ. Рядом с организацией видно состояние ЛМ. При ошибке чтения ЕСМ строка остаётся в списке с указанием причины. Настройка доступна после подтверждения регистрации.
- **Оформление.** Мастер на AntdUI рассчитан в том числе на компактные окна. Активная вкладка выделена тёмным фоном, «Служебные операции ЛМ ЧЗ» открываются по центру основного окна. У программы новый значок. Подробности результата можно скрыть, освободив место. После успешного повтора прежняя ошибка исчезает, записи остаются в «Журнале». Длинные строки журнала переносятся при просмотре, текст можно скопировать.
- **Контроллеры.** На запуск контроллера отводится до 180 секунд. Как только служба и её порты готовы, настройка продолжается. В журнале ожидания и сообщении об ошибке видны фактическое состояние службы Windows и PID. Команда «Сбросить контроллеры…» показывает план, снимает дополнительные контроллеры MultiKKT и возвращает настройки штатной службы. Установленные ЛМ и регистрации ККТ в ЕСМ сохраняются.
- **Обновления и поддержка.** При запуске программа один раз проверяет наличие стабильной версии в официальном репозитории GitHub. Данные касс не отправляются. Загрузка и установка выполняются вручную, при отсутствии сети работа продолжается. Предложение добровольной поддержки появляется в конце процесса после успешной регистрации новых касс. Раздел поддержки также доступен через «Справка».

## Установка и обновление

1. Скачайте `MultiKKT-ESM-TSPioT-11.3.38.0.zip` и `SHA256SUMS-MultiKKT-11.3.38.0.txt` из этого выпуска. Сверьте SHA-256 архива.
2. Закройте предыдущую версию. Распакуйте архив целиком в новую локальную папку. Оставьте DLL и каталог `Provisioner` рядом с основным EXE.
3. Запустите `MultiKKT-ESM-TSPioT.exe`, подтвердите запрос UAC. Руководство доступно через «Справка» → «Открыть инструкцию».

При подготовке выпуска использовались автоматические проверки и демонстрационные данные. Физическая ККТ, бизнес-инициализация ЛМ, реальная продажа и работа на мониторах с разным системным DPI в этом прогоне не проверялись. Для приёмки на подготовленной кассе используйте `FIELD_TEST.md` из ZIP.
