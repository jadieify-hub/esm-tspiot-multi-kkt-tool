# 11.3.22.0 — .NET Framework 4.8 для ЛМ ЧЗ, причина ошибки 1603

- Новое: перед автоматической настройкой и кнопкой «Настроить контроллеры и ЛМ ЧЗ» программа проверяет, установлен ли .NET Framework 4.8. Без него MSI ЛМ ЧЗ не ставится: при обычной установке он сам предлагает скачать .NET, а при тихой установке из программы завершался ошибкой 1603. Теперь настройка не начинается, программа предлагает открыть страницу загрузки .NET 4.8 и напоминает перезагрузить компьютер после установки. Если все ЛМ ЧЗ на другом компьютере, проверка не выполняется.
- Журнал: при ошибке установки MSI ЛМ ЧЗ программа ведёт журнал установщика Windows (`C:\ProgramData\KRS\MultiKKT\InstallerLogs`, без подробного режима и без значений свойств) и добавляет к ошибке строки с причиной и путь к журналу. При 1603 без .NET 4.8 в реестре к ошибке добавляется подсказка про .NET.
- Исправлено: создание экземпляров и регистрация ККТ в ЕСМ ждут ответа до 120 с вместо 30: на кассе ЕСМ отвечал дольше, запрос объявлялся неудачным, а ЕСМ доделывал его уже после повтора. Индикатор длинного шага показывает, когда шаг начат.
- Проверено: полная матрица сборки и тестов. Окно проверки .NET на компьютере без .NET 4.8 и журнал установщика на реальной ошибке 1603 в рамках выпуска не проверялись.

## Установка и ограничения

Нужны Windows, .NET Framework 4.8, права администратора, штатные ЕСМ/ТС ПИоТ и Драйвер ККТ АТОЛ v.10. Для обычного режима нужен установленный `ЕСП Контроллер ЛМ ЧЗ` любой сборки; официальный MSI ЛМ ЧЗ оператор выбирает отдельно. После установки .NET Framework 4.8 перезагрузите компьютер, иначе ЛМ ЧЗ не установится.

Скачайте `MultiKKT-ESM-TSPioT-11.3.22.0.zip` и `SHA256SUMS-MultiKKT-11.3.22.0.txt`, проверьте SHA-256 и распакуйте ZIP целиком в новую папку. Не смешивайте EXE, DLL и `Provisioner` разных версий.

API ЛМ ЧЗ работает по HTTP без шифрования: открывайте сервер ЛМ ЧЗ только во внутренней сети или через VPN, не в интернет.

В поставке нет Firebird, FMU-API, вендорных MSI, `lmcontroller.exe`, отдельного Erlang runtime или данных клиента. Бизнес-инициализация ЛМ и проверка кассового ПО выполняются отдельно.

Полевой чек-лист остаётся планом проверки: непройденные испытания текущего выпуска не объявляются успешными.
