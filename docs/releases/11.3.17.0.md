# 11.3.17.0 — завершение настройки и отдельная кнопка Frontol

- Удалён обязательный опрос `/api/v2/info` после привязки, в конце установки и при обновлении таблицы. Медленный запуск последнего ЛМ больше не превращает выполненную настройку в частичный результат и не мешает обычному предложению поддержки разработки.
- Проверки регистрации, установки служб, автозапуска и применения настроек сохранены. Готовность ЛМ можно проверить отдельно кнопкой `Диагностика по ЕСМ` на вкладке `ЛМ ЧЗ`; результат установки не означает готовность продажи или завершённую бизнес-инициализацию.
- `Настроить Frontol...` — самостоятельная кнопка на вкладке `Автоматическая настройка`. Её можно использовать после ручной настройки или после перезапуска MultiKKT; повторная регистрация и установка ЛМ не запускаются.
- Для Frontol заново читаются кассовый `Frontol.ini`, COM-порты и серийные номера ККТ, подтверждённая регистрация и фактические порты ЕСМ. Перед записью показываются прежние и новые значения; транзакция, снимок отката и контрольное чтение базы сохранены.
- Новых зависимостей нет: используется Firebird, уже установленный вместе с Frontol.

Для обновления закройте MultiKKT и распакуйте ZIP целиком в отдельную папку. Не смешивайте основной EXE, DLL и папку Provisioner от разных версий. Перед настройкой Frontol закройте кассовое приложение и администратор, после изменения настроек запустите Frontol заново.

Скорость пересборки MSI-клонов в этой версии не менялась. Аппаратная приёмка на физическом кассовом стенде остаётся необходимой. Публикация этой сборки в GitHub Releases не выполнялась.
