# MultiKKT 11.3.41.0

Стабильный выпуск для Windows 10/11 и .NET Framework 4.8.

- **Проверка связи с Честным ЗНАКом.** В «Обзоре касс» выберите зарегистрированную ККТ и нажмите «Проверить связь с ЧЗ». Программа отправит через ЕСМ один запрос со встроенной контрольной маркой выбывшего товара. Результат покажет онлайн-ответ ГИС МТ, офлайн-ответ ЛМ ЧЗ или причину, которую удалось определить по ответу ЕСМ. Сканер, товар и чек не нужны.
- **Уже установленный ЛМ ЧЗ.** Укажите адрес и API-порт готового ЛМ на этой кассе или на другом компьютере. MultiKKT настроит привязку без переустановки самого ЛМ. Выберите ЛМ, настроенный для ИНН нужной кассы.
- **Адреса в «Обзоре касс».** Выбранный адрес ЛМ, адрес по данным MultiKKT и адрес контроллера для ЕСМ видны отдельно. Состояние применения отражает сравнение учётных данных, а фактическую связь показывает диагностика.
- **Подтверждение установки ЛМ.** В окне перечислены ККТ и ИНН текущего плана. В режиме «По одной кассе» в подтверждении видна выбранная ККТ.

Скачайте ZIP и файл SHA-256, сверьте сумму и распакуйте ZIP целиком в отдельную папку. Запустите `MultiKKT-ESM-TSPioT.exe` вместе с DLL и каталогом `Provisioner`.

Контрольную марку проверили скриптом через боевой ЕСМ. Касса получила онлайн-ответ с `sold: true`. Изменения настройки ЛМ и кнопку в приложении проверяли на автоматизированных стендах.
