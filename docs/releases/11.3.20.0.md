# 11.3.20.0 — любая сборка штатного контроллера ЛМ ЧЗ

- Исправлено: после обновления ЕСП `lmcontroller.exe` пересобирается даже без смены номера версии, и «Шаг 2: контроллеры» отказывал с сообщением «Штатная служба esm-lm-controller не подтверждена». Программа больше не сверяет контроллер по размеру и SHA-256 одной сборки: штатный контроллер опознаётся по пути установки и подписи ЕСП, полную проверку подписи выполняет помощник перед операцией.
- Штатная служба `esm-lm-controller` опознаётся по имени и пути к контроллеру. Режим запуска, зависимости и политика восстановления, которые меняются от версии к версии вендора, больше не делают её «неподтверждённой».
- Если штатный контроллер всё же не принят, сообщение называет причину: служба не установлена, служба запускает другой файл, файла нет или подпись не ЕСП.
- Путь службы без кавычек (`C:\Program Files\...`) читается целиком.
- Проверено: полная матрица сборки и тестов, приём пересобранного вендором контроллера 1.6.4.0 на реальной машине. Создание клонов контроллеров с новой сборкой вендора на физической кассе в рамках выпуска не проверялось.

## Установка и ограничения

Нужны Windows, .NET Framework 4.8, права администратора, штатные ЕСМ/ТС ПИоТ и Драйвер ККТ АТОЛ v.10. Для обычного режима нужен установленный `ЕСП Контроллер ЛМ ЧЗ` любой сборки; официальный MSI ЛМ ЧЗ оператор выбирает отдельно.

Скачайте `MultiKKT-ESM-TSPioT-11.3.20.0.zip` и `SHA256SUMS-MultiKKT-11.3.20.0.txt`, проверьте SHA-256 и распакуйте ZIP целиком в новую папку. Не смешивайте EXE, DLL и `Provisioner` разных версий.

В поставке нет Firebird, FMU-API, вендорных MSI, `lmcontroller.exe`, отдельного Erlang runtime или данных клиента. Бизнес-инициализация ЛМ и проверка кассового ПО выполняются отдельно. Перед изменением Frontol нужна штатная резервная копия базы; меняются только адрес и порт ЕСМ.

Полевой чек-лист остаётся планом проверки: непройденные испытания текущего выпуска не объявляются успешными.
