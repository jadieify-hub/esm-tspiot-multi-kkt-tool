# 11.3.25.0 — ЛМ ЧЗ на загруженной кассе

- Установка ЛМ ЧЗ ограничена часом вместо 15 минут, ожидание запуска ЛМ — 30 минутами вместо 5. На кассе с процессором, занятым службами драйвера АТОЛ, базовый ЛМ ставился дольше 15 минут, а его ядро открывало порты дольше 15 минут.
- Клон ЛМ: вендорский MSI оставляет после удаления ключ реестра «…экземпляр N» и при следующей установке ставит клон в записанный там каталог Program Files (x86)\RegimeN. Такой ключ теперь считается своим и удаляется при очистке, вместо бесконечного «очистка будет повторена».
- Перед установкой ЛМ программа находит в ProgramData\KRS\MultiKKT папки, которые может менять обычная учётная запись (так бывает после кнопки «Продолжить» в Проводнике), и с согласия оператора оставляет право изменения только администраторам и SYSTEM.
- Журнал: ошибки проверки прав и чужого ключа клона называют путь и значения.
- Проверено: полная матрица сборки и тестов. На физической кассе выпуск не проверялся.

## Установка и ограничения

Нужны Windows, .NET Framework 4.8, права администратора, штатные ЕСМ/ТС ПИоТ и Драйвер ККТ АТОЛ v.10. Для обычного режима нужен установленный `ЕСП Контроллер ЛМ ЧЗ` любой сборки; официальный MSI ЛМ ЧЗ оператор выбирает отдельно. После установки .NET Framework 4.8 перезагрузите компьютер, иначе ЛМ ЧЗ не установится.

Скачайте `MultiKKT-ESM-TSPioT-11.3.25.0.zip` и `SHA256SUMS-MultiKKT-11.3.25.0.txt`, проверьте SHA-256 и распакуйте ZIP целиком в новую папку. Не смешивайте EXE, DLL и `Provisioner` разных версий.

API ЛМ ЧЗ работает по HTTP без шифрования: открывайте сервер ЛМ ЧЗ только во внутренней сети или через VPN, не в интернет.

В поставке нет Firebird, FMU-API, вендорных MSI, `lmcontroller.exe`, отдельного Erlang runtime или данных клиента. Бизнес-инициализация ЛМ и проверка кассового ПО выполняются отдельно.

Полевой чек-лист остаётся планом проверки: непройденные испытания текущего выпуска не объявляются успешными.
