# MultiKKT 11.3.50.0

После принятия запроса инициализации MultiKKT один раз читает состояние ЛМ ЧЗ выбранной кассы. Если ЕСМ уже выполняет инициализацию (код 2073), программа сразу показывает «Инициализация уже идёт».

Периодический опрос отключён. Окно можно закрыть. Для проверки позже откройте «Обзор касс» и нажмите «Диагностика выбранной ККТ».

Для обновления распакуйте ZIP целиком в отдельную папку и запустите MultiKKT. Требуются Windows 10/11 и .NET Framework 4.8.
