# 11.3.16.0 — FMU-API и Frontol

- Две независимые опции, по умолчанию выключены: подготовка ККТ и ЛМ ЧЗ для FMU-API без контроллеров и автоматическое заполнение адреса/порта ЕСМ в Frontol.
- Frontol: база из кассового Frontol.ini, сопоставление по COM и подтверждённому серийному номеру, транзакция, контрольное чтение и восстановление прежних значений из снимка.
- Поставка не содержит Firebird, FMU-API и новых рантаймов: используется isql.exe штатного Firebird на клиентском компьютере. Стандартный режим с контроллерами сохранён.

Для обновления закройте MultiKKT и распакуйте новый ZIP целиком в отдельную папку. Все файлы приложения и папки Provisioner должны быть одной версии; переносить один EXE поверх старой поставки нельзя.

Подготовка FMU-API не устанавливает сам FMU и не инициализирует ЛМ. Для Frontol проверена версия 6.28.8.87 с Firebird 2.1 и COM-подключением АТОЛ; после записи требуется перезапуск Frontol. Полевая проверка полного сценария с физическими ККТ ещё необходима. Публикация этой сборки в GitHub Releases не выполнялась.
