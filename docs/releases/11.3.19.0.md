## Установка и ограничения

Нужны Windows, .NET Framework 4.8, права администратора, штатные ЕСМ/ТС ПИоТ и Драйвер ККТ АТОЛ v.10. Для обычного режима нужен установленный `ЕСП Контроллер ЛМ ЧЗ`; официальный MSI ЛМ ЧЗ оператор выбирает отдельно.

Скачайте `MultiKKT-ESM-TSPioT-11.3.19.0.zip` и `SHA256SUMS-MultiKKT-11.3.19.0.txt`, проверьте SHA-256 и распакуйте ZIP целиком в новую папку. Не смешивайте EXE, DLL и `Provisioner` разных версий.

В поставке нет Firebird, FMU-API, вендорных MSI, `lmcontroller.exe`, отдельного Erlang runtime или данных клиента. Бизнес-инициализация ЛМ и проверка кассового ПО выполняются отдельно. Перед изменением Frontol нужна штатная резервная копия базы; меняются только адрес и порт ЕСМ.

Полевой чек-лист остаётся планом проверки: непройденные испытания текущего выпуска не объявляются успешными.
