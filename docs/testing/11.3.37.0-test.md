# MultiKKT 11.3.37.0-test

Локальная тестовая сборка для Windows 10/11 и .NET Framework 4.8.
Распакуйте ZIP целиком в отдельную папку и запускайте MultiKKT-ESM-TSPioT.exe
рядом с папкой Provisioner. В заголовке окна должна быть версия 11.3.37.0-test.

## Проверка интерфейса

1. Откройте «Обзор касс» в окне шириной 1000 пикселей. Столбец «Состояние ЛМ»
   следует за организацией и целиком виден без горизонтальной прокрутки.
2. Выберите настройку ЛМ зарегистрированной ККТ. Карточка с ИНН и номером
   ККТ расположена над списком. При размере окна 920×640 и масштабе 100%
   поля адреса, порта, логина и пароля одного удалённого ЛМ доступны без прокрутки.
3. Выберите «На другом компьютере». Пустой или некорректный адрес и
   недопустимый порт получают отдельные пояснения. Для порта контроллера
   появляется предупреждение о резервировании. После исправления пояснение
   исчезает. Для проверки полей достаточно закрыть редактор без применения.
4. На вкладке настройки кнопка автоматического режима называется
   «Найти и зарегистрировать кассы». Она запускает регистрацию подключённых
   касс. Для поиска без регистрации используйте режим «По одной кассе».
5. Длинные строки журнала переносятся по ширине окна. Файл журнала и
   копирование диагностики используют сохранённый текст.

Проверка обновлений сохранена из [11.3.36](11.3.36.0-test.md).
На физической кассе эта версия ещё не проверена.
