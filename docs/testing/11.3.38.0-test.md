# MultiKKT 11.3.38.0-test

Локальная тестовая сборка для Windows 10/11 и .NET Framework 4.8. Распакуйте ZIP целиком в отдельную папку и запустите MultiKKT-ESM-TSPioT.exe рядом с папкой Provisioner.

1. Выберите «Обзор касс», затем «Журнал». Активный раздел имеет тёмно-бирюзовый фон, белую надпись и значок. Наведение обозначается светлым оттенком. При навигации с клавиатуры видна рамка фокуса.
2. Переместите основное окно, откройте «Сервис» → «Служебные операции ЛМ ЧЗ…». Служебное окно открывается по центру основного в пределах рабочей области экрана. Закройте, переместите основное окно и откройте снова. Если служебное окно уже видно, повторная команда активирует его на прежнем месте.
3. При ошибке поиска ККТ нажмите «Скрыть» возле подробностей. Освобождается место под карточкой, краткое сообщение остаётся сверху, а подробности доступны в «Журнале». Новая ошибка вновь показывает блок. После успешного повторного поиска мастер переходит к выбору кассы.
4. Внешний вид таблиц, мастер удалённого ЛМ и запуск регистрации можно проверить по инструкции 11.3.37. Для проверки оформления регистрация, установка служб и изменение Frontol не требуются.
