# MultiKKT 11.3.35.0-test

Локальная рабочая сборка на основе 11.3.34, без публикации. Распакуйте весь ZIP
в новую папку и запускайте MultiKKT-ESM-TSPioT.exe с папкой Provisioner.
Нужны Windows 10/11, .NET Framework 4.8, права администратора и установленное
официальное ПО ЕСМ/контроллера. Иконка, ожидание контроллера 180 секунд и предложение
поддержки в конце процесса после успешной регистрации сохранены.

## Изменения

- Перед фактической установкой локального ЛМ показываются MSI, версия и полный
  путь. Можно установить эту версию, выбрать другой пакет или отменить. Проверка
  официального пакета сохранена. Для удалённого или уже установленного ЛМ новое
  подтверждение не появляется; существующий helper всё ещё требует выбранный MSI
  для проверки уже установленных модулей.
- В «Обзор касс» → «Служебные операции» появилась кнопка «Сбросить контроллеры…».
  До изменения показывается перечень. Учтённые контроллеры снимаются по манифестам;
  оставшиеся дополнительные службы проверяются по точному имени, пути и признакам
  принадлежности MultiKKT. Неизвестные службы сохраняются с объяснением в журнале.
  Штатная esm-lm-controller не удаляется: восстанавливаются прежние настройки.
  Если штатная служба остановлена, сброс не пытается принудительно запускать её.
  ЛМ, их данные, файлы установленного ПО и регистрации ЕСМ сохраняются. Старые
  профили ЛМ не удаляются. Возврат экземплярной конфигурации ЕСМ может перезапустить
  соответствующую службу ЕСМ. Неполный сброс не объявляется успешным.
- Прежняя кнопка уточнена: «Удалить контроллеры и ЛМ…». Она по-прежнему снимает
  также созданные программой ЛМ; для повторных попыток используйте отдельный сброс.
- Если список ЕСМ содержит кассу, но её подробности не читаются, строка остаётся
  с реальным ID, портами и причиной отказа. ИНН/ФН не выдумываются; настройка такой
  строки недоступна до подтверждения регистрации. Сохранённые параметры не стираются.
  Восстановление ЕСМ возвращает обычную строку, настоящее удаление убирает её.

## Проверка на кассе

Проверьте подтверждение старого/нового MSI, отсрочку, обновление после ошибки ЕСМ
и сброс дополнительных контроллеров на тестовом стенде. После сброса проверьте,
что штатная служба, ЛМ и регистрации остались. Сохраните журнал при частичном отказе.
Сборка не обещает устранить причины 2003 или остановки штатного контроллера:
эти причины требуют журнала соответствующего компонента.

Автоматические проверки не устанавливают MSI и не удаляют службы рабочего ПК.
На физической кассе эта версия ещё не проверена.
