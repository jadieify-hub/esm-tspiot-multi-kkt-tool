# MultiKKT 11.3.28.0-test — проверка пошагового интерфейса

Локальная тестовая версия без публикации. Распакуйте ZIP целиком в новую папку,
не смешивайте файлы с другими версиями. Требования прежние: Windows,
.NET Framework 4.8, ЕСМ, драйвер АТОЛ 10 и права администратора.
Перед опросом ККТ закройте Frontol и тест драйвера. Для локального ЛМ нужен
официальный MSI, для обычного режима — штатный контроллер ЛМ ЧЗ.

## Автоматически

1. На вкладке «Настройка ККТ» оставьте «Автоматически» и проверьте адрес ЕСМ.
2. Нажмите «Начать автоматическую настройку». Программа последовательно найдёт
   подключённые ККТ и зарегистрирует их. Дождитесь результата.
3. На этом же экране появится выбор размещения ЛМ для каждого ИНН.
   По умолчанию — «На этом компьютере»: ЛМ установит программа, адрес и порт
   назначаются автоматически. Для уже установленного сетевого ЛМ выберите
   «На другом компьютере» и введите адрес и порт.
4. Логин и пароль ЛМ по умолчанию — admin/admin. При необходимости измените их.
   Для локального размещения выберите официальный MSI, если он ещё не указан.
5. Нажмите «Настроить ЛМ для N ККТ» (кнопка показывает число касс). В результате будут отдельно
   показаны выполненные действия и ошибки. «Отложить» оставляет регистрацию
   без дальнейшей установки. Вернуться можно кнопкой настройки зарегистрированных ККТ.

## По одной кассе

1. Выберите «По одной кассе» → «Найти ККТ». Сам поиск ничего не регистрирует.
2. Щёлкните нужную строку. Проверьте ККТ, ФН, ИНН и порты.
   У ещё не созданной кассы порты можно изменить; порты существующего экземпляра защищены от редактирования.
3. Нажмите «Зарегистрировать выбранную ККТ». Если экземпляр уже создан,
   предлагается завершить его регистрацию, без повторного создания.
4. После регистрации выберите размещение ЛМ на том же экране и нажмите
   «Применить к выбранной ККТ». Настраивается только эта касса.
5. Для следующей кассы щёлкните её строку. Отдельной кнопки выбора нет.
   Черновики адресов, включая незаконченный ввод, сохраняются при переключении строк.

Для уже зарегистрированной кассы повторная регистрация не запускается.
После применения параметров доступны изменение настроек и отдельная диагностика.

## Что где находится

- «Настройка ККТ» — поиск, регистрация, размещение и применение ЛМ.
- «Кассы и ЛМ ЧЗ» — текущие кассы, фактическое состояние локальных компонентов,
  настройка выбранной кассы и диагностика только выбранной ККТ.
- «Журнал» — подробности выполнения и копирование диагностики.
- «Параметры…» у адреса ЕСМ — порт драйвера dkktPort (обычно 4042;
  это не GRPC-порт теста драйвера АТОЛ).
- «Сервис» — сервер ЛМ ЧЗ и служебные операции. Удаление компонентов находится
  в служебном разделе и сохраняет проверку владения.
- «Настроить Frontol…» — самостоятельное действие; доступно и после настройки ЕСМ вручную.
- «Справка» → «Поддержать разработку» — добровольная поддержка, без окна после настройки.

## Повтор и остановка

«Остановить» и закрытие окна ждут безопасного завершения текущей операции.
Успешные действия не откатываются. При частичном результате проверьте строку
проблемной кассы и продолжите её настройку.

Перед применением программа заново сверяет выбранные регистрации в ЕСМ.
При изменении адреса ЕСМ, ФН, ИНН или портов требуется обновить данные;
старый план не применяется. Новые посторонние кассы не добавляются в исходный набор автоматически.

## Ограничения

Один ЛМ используется кассами одного ИНН. Изменение размещения для ИНН может
потребовать перенастройки остальных касс этого ИНН; ручное применение меняет
контроллер и привязку только выбранной ККТ.

Адреса сохраняются по ИНН. Логины и пароли действуют только в текущем сеансе,
после перезапуска снова предлагается admin/admin. При смене адреса учётные
данные предыдущего сервера не переносятся автоматически.

Флажок для FMU-API только пропускает создание контроллеров и привязку к ЕСМ.
Сам FMU-API программа не устанавливает и не изменяет.

Успешное применение параметров не подтверждает бизнес-инициализацию ЛМ или
готовность продажи. Их, проверку марки и работу Frontol проверяют отдельно.
Перед записью во Frontol сделайте штатную резервную копию базы; меняются
только адрес и порт ЕСМ у сопоставленных ККТ.

## Проверка на стенде

- Две новые ККТ: автоматический сценарий и ручная настройка второй, затем первой.
- Один и разные ИНН; локальные, сетевые и смешанные ЛМ.
- «Отложить», смена строки с незавершённым адресом, возврат к черновику.
- Ошибка одного ЛМ или привязки: результат остальных касс не теряется.
- Остановка во время опроса и установки, затем продолжение.
- Удаление ЛМ через панель управления: строка ККТ остаётся, состояние ЛМ — «Не установлен».
- Диагностика выбранной кассы; отдельная настройка Frontol.

Автоматические проверки используют подмену внешнего оборудования.
На реальных ККТ и сервере ЛМ эта сборка ещё не проверялась. Не опубликована.
