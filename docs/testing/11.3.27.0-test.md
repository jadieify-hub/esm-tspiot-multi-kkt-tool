# MultiKKT 11.3.27.0-test — локальная проверка нового интерфейса

Тестовая сборка без публикации. За основу взята 11.3.26.0.

## Автоматический режим

1. Закройте Frontol и тест драйвера, если они удерживают ККТ.
2. Нажмите «Зарегистрировать и настроить» на вкладке автоматической настройки.
3. После регистрации появится «Настройка ЛМ ЧЗ» со списком ИНН и касс.
4. Для каждого ИНН оставьте «На этом компьютере» либо выберите «На другом
   компьютере», укажите адрес и порт существующего ЛМ. Логин/пароль — admin/admin
   по умолчанию, при необходимости измените их.
5. «Настроить» продолжит установку локальных ЛМ и настройку подключения.
   MSI запрашивается только при локальных ЛМ. «Отложить» сохранит регистрацию
   касс без дальнейшей установки.

## Ручной режим

1. Откройте «Ручное подключение» и нажмите «Найти ККТ».
2. Дождитесь последовательного поиска. В списке появятся и незарегистрированные
   кассы; сам поиск их не регистрирует.
3. Выберите строку. Проверьте серийный номер, ФН, ИНН, порты ЕСМ и кассового ПО.
4. Нажмите «Настроить выбранную ККТ». Регистрируется только выбранная касса,
   затем открывается такое же окно ЛМ ЧЗ, как в автоматическом режиме.
5. После результата выберите следующую кассу. Отдельные операции доступны
   в раскрываемом разделе для ручного ввода и восстановления.

## Уже зарегистрированные кассы

Кнопка «Настроить подключение ЛМ ЧЗ…» на вкладке «ЛМ ЧЗ» открывает окно выбора
размещения и учётных данных. Регистрация при этом повторно не запускается.

Адреса удалённых ЛМ сохраняются по ИНН. Введённые логины и пароли действуют
только в текущем сеансе: после перезапуска программа снова предлагает admin/admin.
Готовность и бизнес-инициализация ЛМ проверяются отдельно; сообщение о принятии
настроек ЕСМ не заменяет проверку продажи/марки.

Режим FMU-API сохраняет прежнее назначение — пропуск контроллеров и привязки.
Сам FMU-API программа не устанавливает и не изменяет.

## Что проверить на стенде

- Две ККТ разных ИНН: поиск, настройка второй строки, затем первой.
- Две ККТ одного ИНН используют один ЛМ.
- Локальное, удалённое и смешанное размещение; чужие назначения сохраняются.
- «Отложить» после регистрации и последующее продолжение.
- Удалённый ЛМ с нестандартными логином/паролем; их нет в журнале.
- Повторный поиск сохраняет изменённые порты ещё не зарегистрированной кассы.

На реальной кассе и сервере авторская аппаратная проверка не проводилась.
Распространение и GitHub Releases для этой сборки пока не выполняются.
