# MultiKKT 11.3.29.0-test — рабочая версия с новым интерфейсом

Непубличная тестовая сборка для Windows 10/11 и .NET Framework 4.8.
Распакуйте ZIP целиком в новую папку: AntdUI.dll, EsmTspiot.Shared.dll и Provisioner
должны остаться рядом с EXE. Запустите программу с правами администратора.
Это рабочая программа; поиск и настройка обращаются к оборудованию.

Нужны установленный ЕСМ и драйвер АТОЛ 10. Для обычного режима также нужен
штатный контроллер ЛМ ЧЗ, для установки локальных ЛМ — официальный MSI.
Перед опросом закройте Frontol и тест драйвера АТОЛ.

## Автоматически

1. На экране «Настройка ККТ» оставьте «Автоматически», проверьте адрес ЕСМ
   и нажмите «Начать автоматическую настройку».
2. Программа последовательно найдёт подключённые ККТ и зарегистрирует их.
3. Затем выберите размещение ЛМ для каждого ИНН. «На этом компьютере» —
   программа установит ЛМ и назначит порты. «На другом компьютере» — укажите
   адрес и порт уже установленного сетевого ЛМ.
4. Логин и пароль по умолчанию admin/admin; при необходимости измените их.
5. Нажмите «Настроить ЛМ для N ККТ». Если нужен локальный ЛМ, выберите
   официальный MSI при запросе и продолжите. Результат покажет выполненные
   действия и ошибки по кассам.

«Отложить» сохраняет регистрацию без дальнейшей установки. Возврат — кнопкой
настройки ЛМ для зарегистрированных ККТ.

## По одной кассе

1. Выберите «По одной кассе» → «Найти ККТ». Поиск ничего не регистрирует.
2. Щёлкните нужную строку и проверьте серийный номер, ФН, ИНН и порты.
   Порты существующего экземпляра защищены от изменения.
3. Нажмите «Зарегистрировать выбранную ККТ». Если экземпляр уже создан,
   предлагается завершить регистрацию без повторного создания.
4. Выберите локальный или сетевой ЛМ и нажмите «Применить настройки ЛМ».
   Настраивается только выбранная касса.
5. Выберите следующую кассу прямо в таблице. Незаконченные адреса и порты
   сохраняются в черновике при переключении строк и экранов.

Для зарегистрированной кассы доступны изменение настроек ЛМ и отдельная диагностика.
Регистрация повторно не выполняется.

## Экраны и команды

- **Настройка ККТ** — мастер поиска, регистрации и применения параметров ЛМ.
- **Обзор касс** — фактические регистрации, адреса и порты, состояние локальных
  компонентов. Настройка выбранной строки возвращает к мастеру; диагностика
  проверяет только выбранную ККТ.
- **Журнал** — подробности операций, папка журналов и копирование диагностики.
- **Параметры…** рядом с ЕСМ — dkktPort, обычно 4042. Это не GRPC-порт 4041 теста АТОЛ.
- **Настроить Frontol…** — самостоятельное действие после автоматической или ручной
  настройки. Закройте Frontol и администратор, сделайте резервную копию базы.
  Меняются только адрес и порт ЕСМ у сопоставленных касс.
- **Сервис** — сервер ЛМ, служебные операции и восстановление Frontol из снимка.
- **Справка → Поддержать разработку** — добровольная поддержка без вмешательства в настройку.

## Остановка, повтор и ограничения

«Остановить» и закрытие окна ждут безопасного завершения текущей операции.
Успешные действия не откатываются. При частичном результате продолжите настройку
проблемной кассы. Перед применением программа сверяет регистрацию в ЕСМ заново:
изменившиеся ФН, ИНН, адрес или порты требуют обновления данных.

Один ЛМ используется кассами одного ИНН. Изменение размещения ИНН может потребовать
перенастройки других касс этого ИНН, но ручное применение меняет контроллер и
привязку только выбранной ККТ. Адреса сохраняются по ИНН. Пароли действуют
в текущем сеансе; смена адреса не переносит пароль предыдущего сервера.

Флажок FMU-API только пропускает контроллеры и привязку к ЕСМ. Сам FMU-API
программа не устанавливает, не настраивает и не изменяет.

Успешное применение не подтверждает бизнес-инициализацию ЛМ, готовность продажи
или проверку марки. Это проверяется отдельно.

## Что проверить на стенде

- Две новые кассы: автоматический сценарий, затем ручной с выбором второй строки.
- Один и разные ИНН; локальный, сетевой и смешанный вариант ЛМ.
- «Отложить», смена строки с незавершённым вводом, возврат из обзора и журнала.
- Ошибка одной кассы, остановка и продолжение без повторения успешных действий.
- Отдельная диагностика выбранной кассы и запись во Frontol после резервной копии.
- Обычный размер окна и масштаб Windows 125/150%: поля и основные кнопки доступны.

Автоматические проверки используют подмену оборудования. Полный сценарий на живой
кассе в этой среде не проверен. Версия пока не публикуется.
