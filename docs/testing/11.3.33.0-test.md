# MultiKKT 11.3.33.0-test

Непубличная сборка на основе 11.3.32. Распакуйте архив целиком в новую папку.
Запускайте MultiKKT-ESM-TSPioT.exe с поставляемой папкой Provisioner.
Нужны Windows 10/11, .NET Framework 4.8 и права администратора.

## Изменения

Выбранная иконка «Корпус и чек» заменяет прежний подробный рисунок.
Она встроена в EXE и назначена всем окнам, включая служебные операции ЛМ ЧЗ,
подключение к ЕСМ, сведения о кассе, редактор ЛМ и поддержку разработки.
В ICO включены размеры 16, 24, 32, 48, 64, 128 и 256 пикселей.

Логика регистрации, настройки и удаления компонентов не менялась.
Лимит запуска контроллера 180 секунд из 11.3.32 сохранён.
Отдельный сброс только контроллеров в эту сборку ещё не добавлен:
«Удалить всё созданное» по-прежнему также снимает созданные программой ЛМ ЧЗ.

## Проверка

Проверьте значок файла, главного окна и дополнительных окон, особенно
«Служебные операции ЛМ ЧЗ». Windows может продолжать показывать старый значок
существующего закреплённого ярлыка из своего кэша.

Автоматические UI-проверки используют тестовый транспорт; работа на физической
кассе в рамках этого изменения не проверялась.
