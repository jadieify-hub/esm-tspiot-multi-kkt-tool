# MultiKKT 11.3.36.0-test

Локальная тестовая сборка на основе 11.3.35, без публикации. Распакуйте весь ZIP
в новую папку. Запускайте MultiKKT-ESM-TSPioT.exe с папкой Provisioner.
Нужны Windows 10/11, .NET Framework 4.8 и права администратора.

## Проверка обновлений

После открытия главного окна программа один раз обращается к публичному API
официального GitHub-репозитория. Запуск и работа с кассами не блокируются.
Тайм-аут — 8 секунд; закрытие программы отменяет запрос.

Если опубликована новая стабильная версия, справа в верхнем меню появляется
«Доступно обновление …». Нажатие открывает фиксированную официальную страницу
releases/latest в браузере. Скачать ZIP и установить нужно вручную. Ссылки
из ответа сервера не исполняются; программа не скачивает и не заменяет файлы.

Сравниваются номера версий; более старый релиз не предлагается. Черновики и
prerelease не предлагаются. Стабильный релиз с тем же номером новее тестовой
сборки. Если локальная тестовая версия выше опубликованной, уведомления нет.

При отсутствии интернета, лимите API или неверном ответе проверка пропускается
без всплывающих ошибок. При сетевой ошибке в журнале появляется короткая запись.
Нет авторизации, токенов и идентификаторов клиента. В запросе нет ИНН, номеров
ККТ/ФН, путей и содержимого журналов; User-Agent содержит название и версию
MultiKKT. GitHub видит стандартное сетевое подключение.

Все возможности 11.3.35 сохранены. Проверка фактического ИНН вручную установленного
ЛМ пока не добавлена: существующее назначение ЛМ берётся из инвентаря MultiKKT.

## Проверки

Автоматические проверки используют подставной HTTP: новая/равная/старая версия,
test → stable, prerelease/draft, ошибка сети, неверный JSON, фоновая работа,
один запрос и закрытие окна во время проверки. Живой публичный API проверяется
отдельно; новый релиз ради теста не публикуется.

На физической кассе эта версия ещё не проверена.
