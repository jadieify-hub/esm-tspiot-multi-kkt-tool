# MultiKKT 11.3.32.0-test

Непубличная рабочая сборка на основе 11.3.31. Распакуйте архив целиком в новую
папку и запускайте MultiKKT-ESM-TSPioT.exe с поставляемой папкой Provisioner.
Нужны Windows 10/11, .NET Framework 4.8 и права администратора. Оформление и
функции 11.3.31 сохранены. Общая инструкция прилагается в INSTRUCTION_FOR_DUMMIES.txt.

## Изменение

Контроллеру отводится до **180 секунд** на запуск службы и открытие принадлежащих
ей портов. Готовый контроллер продолжает настройку сразу, без обязательной паузы.
Этот лимит применяется также при перезапуске контроллера; ожидание его остановки
и правила запуска/восстановления служб не менялись.

Журнал ожидания показывает имя службы, состояние SCM (например, StartPending,
Running, Stopped) и PID. Одинаковые состояния не записываются каждый цикл опроса.
Отсутствующая служба, неоткрытые порты и порты чужого процесса различаются.
При исчерпании времени в ошибке остаётся результат последней проверки.

## Проверка на кассе

Повторите настройку проблемной ККТ. Если контроллер готов раньше трёх минут,
настройка должна сразу перейти дальше. Если он не готов, сохраните журнал:
теперь по нему будет видно состояние службы и PID в конце ожидания.

Увеличение лимита не восстанавливает упавшую службу и не подменяет проверку
готовности успешным результатом. На физической проблемной кассе изменение
ещё не проверялось; причина прежнего отказа по старому журналу не установлена.
