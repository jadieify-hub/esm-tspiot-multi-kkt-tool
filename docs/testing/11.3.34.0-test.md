# MultiKKT 11.3.34.0-test

Локальная тестовая сборка на основе 11.3.33. Распакуйте архив целиком в новую
папку и запускайте MultiKKT-ESM-TSPioT.exe с папкой Provisioner.
Нужны Windows 10/11, .NET Framework 4.8 и права администратора.

После успешной регистрации новых касс в ЕСМ существующее окно поддержки
показывается один раз в конце процесса: после попытки настройки ЛМ/контроллеров
либо после «Отложить». До выбора размещения ЛМ оно не появляется.
Ошибка настройки ЛМ или контроллера не блокирует предложение, если регистрация
в ЕСМ прошла успешно. Окно открывается после снятия блокировки интерфейса.

Ошибки регистрации, простое чтение ранее зарегистрированных ККТ, обновление
таблицы и диагностика не вызывают предложение. При закрытии приложения показ
подавляется. Раздел «Справка → Поддержать разработку» по-прежнему доступен всегда.
Открытие окна ничего не отправляет в сеть; ссылка и QR не менялись.

Новая иконка и лимит запуска контроллера 180 секунд сохранены. Отдельный сброс
только контроллеров и подтверждение сохранённого MSI в эту версию не включены.
«Удалить всё созданное» по-прежнему снимает также созданные программой ЛМ ЧЗ.

Проверка: зарегистрировать ККТ в ручном или автоматическом режиме, затем
настроить ЛМ либо отложить. После завершения должно появиться одно окно
поддержки. Повторное открытие настройки/отсрочка без новой регистрации не должны
вызывать его снова. На физической кассе изменение ещё не проверено.
