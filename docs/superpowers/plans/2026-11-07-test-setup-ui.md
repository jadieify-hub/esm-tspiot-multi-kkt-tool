- [x] Окно ЛМ по ИНН: local/remote, адрес/порт, session credentials,
  маскированный пароль, слияние выбранных ИНН; методы PromptLmSetup(owner, kkts)
  и GetLmCredentials(inn). Существующие map helpers остаются общими.
- [x] Разрешить scoped controller ensure для второй кассы при сохранённой базе;
  сохранить ownership и canonical проверки. Скрыть login/password в ошибках
  привязки. RED→GREEN в существующих Shared/Provisioner tests.
- [x] Ручной список обнаружения и выбор одной кассы, сохранение полей при
  повторном поиске; использовать BulkRegistrationWorkflow и Sequential coordinator.
  Общий поиск используется автоматом. Подключить окно ЛМ после регистрации,
  убрать ранний MSI prompt и дублирующее меню. UI-проверки через fake API.
- [x] Версия/инструкция тестовой сборки; полная матрица без аппаратных мутаций,
  итоговое независимое ревью, ZIP и SHA256 в artifacts/test, без публикации.

## Существенные решения

- Credentials только в памяти: не добавляем новый секретный persistence.
- Для selected ensure используются полный сохранённый инвентарь и только
  выбранные запросы; соседние ККТ не подмешиваются в пакет.
- Для исходного ввода сохраняется существующая ручная форма, основной путь —
  поиск → выбранная строка → регистрация → общий диалог ЛМ.
- Установка завершена и фактическая готовность ЛМ — разные результаты.
