# Reliability And UX Hardening Implementation Plan

**Goal:** Усилить API-контракты, сделать массовую регистрацию возобновляемой и управляемой, адаптировать WinForms для малых экранов и улучшить диагностику.

**Architecture:** `ITspiotApiClient` отделяет workflow от HTTP. Строгие парсеры возвращают ошибку формы ответа. `BulkRegistrationWorkflow` исполняет план последовательно и сообщает прогресс; `MainForm` отвечает только за ввод, подтверждение и отображение. Журнал дублируется локальным файловым sink.

## Task 1: строгие контракты и модели

- Добавить failing tests для неправильной формы JSON и детального `regData`.
- Ввести строгие DTO/парсеры списка экземпляров, ДККТ и детали экземпляра.
- Добавить пути detail/settings и методы клиента с cancellation token.
- Добавить fake `HttpMessageHandler` и проверить методы, URL и точные JSON-поля.

## Task 2: валидация и безопасность ввода

- Добавить failing tests для Unicode-цифр и удаленного base URL.
- Ограничить цифровые поля ASCII-цифрами.
- Добавить предупреждение для не-loopback URL без блокировки существующих сценариев.

## Task 3: workflow массовой регистрации

- Добавить интерфейс API и тестовый fake-клиент.
- Добавить failing tests: новый экземпляр POST+PUT, существующий зарегистрированный пропускается, существующий без `regData` получает PUT, ошибка одного не прерывает следующий, отмена прекращает новые операции.
- Реализовать `BulkRegistrationWorkflow`, progress-модель и ограниченный retry транзитной 1013.
- Сохранить текущие итоговые статусы и добавить `Cancelled`/`RecoveredRegistration` при необходимости.

## Task 4: компактный UI

- Создать `BulkRegistrationDialog` с прокручиваемым `DataGridView`, подтверждением, статусом и отменой.
- Перевести массовый обработчик формы на workflow.
- Ограничить размер по `Screen.WorkingArea`, включить вертикальную прокрутку корневой панели и сократить подписи портов.
- Сохранить четыре существующие кнопки и их обработчики.

## Task 5: файловый и маскированный журнал

- Добавить failing tests маскирования и устойчивости файлового sink.
- Реализовать `DiagnosticMasker` и `FileLogSink`.
- Добавить кнопку `Скопировать диагностику`; видимый журнал оставить редактируемым.

## Task 6: документация и проверка

- Обновить README и инструкцию без персональных путей/данных.
- Явно разделить legacy-зависимый и modern self-contained варианты.
- Прогнать все тесты, собрать новый EXE `MultiККТEsmTspiot-compact9-hardened.exe`.
- Проверить UI Automation и размер окна на виртуальной рабочей области 800x600.
