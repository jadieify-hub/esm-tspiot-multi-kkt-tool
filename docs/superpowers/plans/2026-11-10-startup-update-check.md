# Проверка обновлений при запуске

В 11.3.36-test добавить однократную фоновую проверку официального GitHub Releases
после появления главного окна. Источник: публичный GET /repos/jadieify-hub/esm-tspiot-multi-kkt-tool/releases/latest.
Только стабильные релизы, сравнение числовой версии; стабильная версия с тем же
номером новее тестовой. Не предлагать откат. Загрузка/установка остаются ручными.

При новой версии в верхнем меню появляется действие «Доступно обновление …»;
оно открывает только фиксированную официальную страницу releases/latest.
Никаких URL из ответа сервера, токенов, данных касс или телеметрии.
Тайм-аут 8 секунд, проверка не блокирует форму и отменяется при её закрытии.
Сетевая ошибка, неверный ответ или отсутствие релиза не вызывают всплывающих окон.

План: тесты сравнения/HTTP границы; общий ReleaseUpdateChecker; подключение
проверки в Program и пункт главного меню; проверки асинхронного UI, ошибки и
закрытия; версии main/helper и README/инструкция; локальный ZIP без публикации.
Тесты используют HttpMessageHandler-фикстуры. Отдельно проверить живой публичный
API без публикации и без изменения служб или настроек клиента.

## Проверено

Реализовано. Проверки сравнения версий и HTTP проходят. UI-проверки обнаружили
реальный повторный Dispose CTS при Close + using; освобождение исправлено,
регрессионный сценарий проходит. Общая матрица завершилась RELEASE_MATRIX_OK:
оба Shared/Operator target, 140 helper-тестов, C# 5/net48, Modern, UI и safety.
Независимое ревью замечаний не обнаружило. Живой вызов общего checker к GitHub
прочитал стабильный v11.3.26.0 (2026-11-10); в тесте передана версия 0.0.0.0.
Готовый ZIP проверен контрактом main/helper, 16 хэшами и UI-прогоном против
распакованного EXE. Публикация и аппаратные проверки не выполнялись.
