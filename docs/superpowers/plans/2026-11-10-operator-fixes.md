# Остаток операторских исправлений MultiKKT

Основа: 11.3.34, локальная рабочая копия lm-server. Сборка 11.3.35-test, без публикации.

1. Перед фактической установкой локального ЛМ показать выбранный MSI, версию и полный путь. Действия: установить, выбрать другой, отмена. Не спрашивать для удалённого ЛМ и при отсутствии установки. Сохраняются проверка официального пакета и существующие алгоритмы.
2. Отдельный сброс контроллеров: удалить дополнительные контроллеры и старые службы MultiKKT, а у штатного вернуть исходное назначение. Сохранить штатную службу, установленное ПО, ЛМ/их данные и регистрации ЕСМ. Перед действием показать конкретный перечень. Не снимать неизвестную службу только по похожему названию. Показать фактические ошибки и незавершённое удаление.
3. Ошибка подробного чтения ЕСМ не удаляет строку известного экземпляра: реальные идентификатор/порты и ошибка остаются видны; неподтверждённая регистрация не допускается к настройке. Удалённый из ЕСМ экземпляр должен исчезать.

Затрагиваются имеющиеся UI и helper, их тесты и документация. Общие протоколы изменения, версии и итоговую сборку координирует основной агент. Минимальные регрессионные тесты: выбранный/отсутствующий/заменённый MSI; пропавшие подробности и восстановление; сброс без удаления ЛМ/штатной службы, сохранение чужих служб и ошибки очистки. Полный прогон UI и нужных helper/shared проверок, независимое итоговое ревью.

## Результат

Все три задачи выполнены. RED подтверждены: отсутствующее подтверждение MSI,
исчезновение строк при ошибках подробностей, потеря сохранённых параметров при
холодном запуске, неподдерживаемый сброс, потеря исходных настроек штатного
контроллера при отсутствующем config.yml. Итоговая общая матрица прошла
RELEASE_MATRIX_OK (Shared/Operator под обеими платформами, C# 5, UI, safety,
Modern). После замечания ревью добавлены тесты остановленного/работающего
штатного контроллера и отсутствующего config: все 140 helper-тестов прошли.
Повторное узкое ревью закрыло замечания. Готовый ZIP проверен контрактом main/helper,
16 хэшами SHA-256 и полным UI-прогоном против распакованного EXE.

Системные службы, MSI и физические ККТ при разработке не изменялись. Проверки
используют фикстуры; реальные аппаратные сценарии остаются для тестовой кассы.
Неизвестные службы, похожие по имени, не удаляются. Сбой ЕСМ не маскируется успехом.
