# Тестовая версия: поиск ККТ и настройка ЛМ ЧЗ

Основание: согласованный с Русланом сценарий и предпроектная проверка Astra
по f07764c. Сборка предназначена для локального тестирования, публикация запрещена.

## Поведение

- Автомат сначала обнаруживает и регистрирует ККТ существующим workflow.
  После регистрации открывает окно настройки ЛМ по ИНН, с действиями
  «Настроить» и «Отложить». Локальное размещение — исходный вариант.
- Можно выбрать существующий удалённый ЛМ и ввести адрес, порт, логин и пароль.
  Начальные учётные данные admin/admin. Один ЛМ на ИНН.
- MSI и .NET проверяются только после выбора и только для локальных ЛМ.
  «Отложить» сохраняет зарегистрированные ККТ без установки компонентов.
- Ручной режим сканирует ККТ без регистрации тем же механизмом, что автомат.
  Таблица показывает обнаруженные ККТ, включая ещё не зарегистрированные.
  Выбранная строка заполняет форму параметров; «Настроить выбранную ККТ»
  регистрирует только её с повторной проверкой физического target lease,
  затем показывает то же окно ЛМ. Прежняя ручная форма остаётся резервом.
- Повторный поиск сохраняет введённые порты для той же кассы и ИНН.
  Порты проверяются по полному списку экземпляров и обнаруженных назначений.
- Сохранённые локальные установки и назначения других касс учитываются при
  планировании, но не включаются в изменяющий пакет выбранной строки.
- Конфигурация ЛМ доступна также с вкладки ЛМ ЧЗ для зарегистрированных касс.
  Журнал и таблицы различают сохранённые параметры и выполненную настройку.
- Адреса сохраняются существующим RemoteLocalModuleStore, только выбранные
  ИНН сливаются с общей картой. Ошибка чтения перед изменением останавливает
  операцию. Учётные данные хранятся только в сеансе, по ИНН и endpoint;
  после перезапуска окно предлагает admin/admin. Пароль скрыт в интерфейсе,
  оба поля маскируются в журнале, включая ошибочные ответы ЕСМ.
- FMU-API не читается и не изменяется. Прежний флаг пропускает контроллеры
  и привязку. Сервер ЛМ ЧЗ, Frontol и поддержка разработчика сохраняются.
- Из верхнего меню убираются дублирующие переходы на вкладки и скрытый
  переход к настройке удалённых адресов; действия доступны на рабочем экране.

## Границы

WinForms, net48 x86/C#5 и существующая modern-сборка. Новых зависимостей нет.
Удалённое ПО не устанавливается; старые локальные ЛМ не удаляются автоматически.
Готовность/инициализация ЛМ не проверяется обязательным финальным опросом.

## Проверка

Поиск не вызывает POST/PUT; регистрация действует на выбранный serial;
повторное сканирование сохраняет параметры; A затем только B при занятой базе;
локальный/удалённый/смешанный выбор; «Отложить» без MSI; admin/admin и разные
credentials для ИНН; HTTP-ошибка не раскрывает credentials. Существующая матрица
сборок и проверок, затем отдельный ZIP 11.3.27.0-test без GitHub-публикации.
Аппаратные проверки остаются для пользовательского стенда.
