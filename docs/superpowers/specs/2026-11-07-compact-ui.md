# Компактная рабочая MultiKKT 11.3.30.0-test

Пользователь одобрил исправление растягивания окна и сокращение перегруженной шапки.
Цель — больше места для таблицы, без изменения регистрации и установки оборудования.

- Штатная рамка Sizable Windows, обычные края, углы, разворачивание и привязка.
  Оформление AntdUI сохраняется внутри окна. Дублирующий PageHeader убирается.
- Одна строка навигации: три раздела слева, компактная кнопка состояния ЕСМ справа.
  Адрес, dkktPort и проверка находятся в отдельном окне подключения.
  Используются прежние TextBox и обработчики; закрытие окна не уничтожает ввод.
- Обзор показывает таблицу и действия выбранной кассы. Служебные операции
  открываются отдельным окном и доступны без зарегистрированных касс.
- Тип, каталог и владение — в сведениях выбранной кассы, без расширения таблицы.
- Работа, отмена, подтверждения удаления, блокировка полей, Frontol и FMU не меняются.
  Открытые служебные окна получают те же состояния busy и закрываются с владельцем.
- Windows 10/11; только локальная тестовая сборка. Без публикации/push/merge.
- Main/helper 11.3.30.0-test, компактный ZIP с прежним составом и лицензиями.

Приёмка: native resizing включён; увеличение окна расширяет таблицу; подключение
и служебные операции не занимают строки обзора; повторное открытие сохраняет ввод;
busy блокирует действия; сценарные проверки и безопасность проходят.
