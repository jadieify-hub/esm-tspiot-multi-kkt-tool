## Поведение

Три вкладки: «Настройка ККТ», «Кассы и ЛМ ЧЗ», «Журнал». В настройке компактный индикатор трёх этапов и выбор «Автоматически» / «По одной кассе». До поиска таблица пустая. Адрес ЕСМ и его доступность видны сверху; порт ДККТ находится в параметрах подключения.

Автомат запускает существующий поиск/регистрацию всего найденного набора. После регистрации показывает встроенный редактор ЛМ по ИНН и возвращается в idle. Применение — отдельная отменяемая операция. Ручной поиск ничего не регистрирует; выбор строки показывает статус и доступное действие: новая касса — регистрация, существующий незавершённый экземпляр — завершение без нового POST, подтверждённая регистрация — настройка ЛМ. Реальный VCOM lease обязателен для регистрации.

Один общий редактор ЛМ используется во встроенном шаге и в резервном диалоге. Локальное размещение по умолчанию, remote host/port, admin/admin, скрытый пароль. Сырые черновики, включая ошибочный порт, сохраняются в памяти по destination+ИНН при переключении строк/режимов/вкладок. Перенос старого пароля на другой endpoint запрещён. Применение в ручном режиме ограничено одной кассой, даже при общем ИНН.

Pending-операция хранит destination, исходный набор serial+instanceID+ФН+ИНН. До сохранения карты адресов и установки — свежий GET и точное сопоставление подтверждённой регистрации. Новые кассы не добавляются в исходный набор. Смена destination инвалидирует найденную карту/отложенную область применения.

MSI запрашивается только для локальных ЛМ после выбора размещения. Отложить сохраняет регистрацию. FMU-API только пропускает контроллеры и привязку. Регистрация, установка, применение и готовность ЛМ отображаются раздельно; заключительного ожидания готовности нет.

Результат показан внутри мастера, частичные сбои сопоставлены с фактическими serial/ИНН результата этапа, не парсятся из журнала. Привилегированные механизмы и проверки владения сохраняются. Во время работы режим/таблица/destination/поля заблокированы. Stop и закрытие окна ждут безопасной границы и освобождения ресурсов; до неё «Останавливаем…».

Кассы и ЛМ используют существующий инвентарь и отдельную диагностику только выбранной кассы. Удаление/старые ручные шаги/сервер доступны как служебные операции. Frontol остаётся отдельной кнопкой с существующим предпросмотром двух полей. Поддержка разработки только через Справку, без дополнительного окна на финише.

## Приёмка

- Пустой старт и три вкладки; авто и ручной маршрут работают без дублирующей навигации.
- Клик строки меняет контекст без записи и не теряет сырой черновик.
- Повторная регистрация подтверждённой кассы не запускается.
- Apply при изменённых destination/ФН/ИНН/instanceID даёт ноль мутаций.
- Операция и закрытие не освобождают UI до фактического завершения.
- Диагностика одного serial не опрашивает соседние кассы.
- 1024×768: основные кнопки доступны, длинные группы прокручиваются; Legacy и Modern собираются.
- Матрица, безопасность, контракт main/helper и ZIP проходят; финальное независимое ревью.
- Локальная тестовая сборка, без push/tag/release. На живой кассе проверяет пользователь.
