# Рабочая тестовая 11.3.29.0-test с оформлением предпросмотра 02

Пользователь поручил сделать рабочую версию для проверки. Внешний ориентир —
prototypes/MultiKKT.AntdPreview и реальные изображения antdui-preview-02, а не
демонстрационные операции из прототипа. Windows 7 исключена по прямому указанию
пользователя; целевые системы Windows 10/11. Публикация не разрешена.

Сохраняются реальные механизмы 11.3.28: физический VCOM lease, регистрация,
сверка области применения, установка/контроллеры/привязка, частичные результаты,
безопасная остановка и закрытие, отдельный Frontol и FMU-пропуск контроллеров.
Демонстрационные кассы и фальшивые успехи в рабочий EXE не переносятся.

Мастер получает оформление 02: контрастные шаги, синий активный режим и действия,
полные номера ККТ, COM шириной 72 px, выделенную карточку выбранной кассы,
локальное/удалённое размещение с сохранением сырых черновиков. Три раздела:
«Настройка ККТ» — мастер; «Обзор касс» — реальные компоненты/адреса/состояния и
диагностика выбранной ККТ; «Журнал» — реальные записи. Обзор не дублирует мастер.

Существующие DataGridView и их контексты остаются источником выбора и результатов;
они оформляются в общей палитре. Это сохраняет проверенные обработчики и исключает
синхронизацию двух таблиц. Кнопки, выбор режима и карточки используют AntdUI 2.4.18.
Текстовые поля сохраняют штатную семантику WinForms внутри оформленного контейнера.
Общий редактор ЛМ сохраняет прежние валидацию и очистку учётных данных.

Операторы net48 x86 и net8 Windows используют общие исходники. Новая UI-зависимость
только у операторов; helper и его доверенная closure не получают AntdUI.
Компактная поставка включает AntdUI.dll, Apache-2.0 и прежние обязательные файлы.
Обе версии main/helper — 11.3.29.0-test. Поддержка разработки остаётся в Справке.

Приёмка: существующие сценарные проверки и безопасность проходят; оформление
сверено по снимкам настоящей формы; отдельность обзора и навигация проверены;
упакованный ZIP запускается и проходит SHA256. Живые кассы проверит пользователь.
