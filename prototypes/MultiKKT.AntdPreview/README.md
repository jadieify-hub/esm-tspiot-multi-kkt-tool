# MultiKKT — проба оформления AntdUI, вариант 02

Второй вариант возвращает акценты утверждённого макета: зелёные завершённые
шаги, синий текущий шаг, контрастную навигацию и более крупные жирные заголовки.
Номер ККТ показан целиком, колонка COM ограничена 72 пикселями; текст статусов
остаётся понятен без различения цветов. Первый ZIP сохранён отдельно для сравнения.

Отдельный интерактивный прототип для оценки внешнего вида. Он не заменяет MultiKKT
11.3.28.0-test и не подключается к ЕСМ, ККТ, службам, MSI или базе Frontol.
Демонстрационные кассы и переходы существуют только в памяти.

## Запуск

Windows 10/11 и .NET Framework 4.8. Распакуйте ZIP целиком и запустите
`MultiKKT.UI-Preview.exe`. Права администратора не нужны.

- Переключайте «Автоматически» / «По одной кассе».
- Основная кнопка проигрывает демонстрационный поиск и настройку.
- Нажмите строку кассы, чтобы сменить выбранную ККТ.
- Переключайте локальный и удалённый ЛМ, вводите адрес и порт. Неверный порт
  подсвечивается и блокирует применение.
- Список «Пример…» внизу сразу открывает начало, найденные кассы, сетевой ЛМ
  или завершение. Вкладки и кнопки служебных операций показывают примеры интерфейса.
- В «Справка» доступны сведения о прототипе и добровольная поддержка разработки.
  Используется существующий диалог MultiKKT с текстовой ссылкой и QR-кодом;
  простое открытие диалога ничего не отправляет.

Нажатия «Проверить» и «Настроить Frontol» не выполняют настоящих операций.

## Устройство

WinForms / .NET Framework 4.8 x86 и пакет [AntdUI 2.4.18](https://www.nuget.org/packages/AntdUI/2.4.18).
Новая библиотека подключена только к этому проекту. Основные проекты и механизмы
настройки не изменены. Браузерный движок и дополнительные службы не используются.

Исходный ориентир — утверждённый первый вариант интерфейса, состояния Р3 и Л2.
Пользователь разрешил пробу AntdUI и отменил требование Windows 7. Это проба
реализуемого оформления, а не очередная сгенерированная иллюстрация.

Проверка перед передачей: сборка, четыре отрисованных состояния, неверный/верный
порт, переход ручного режима только для выбранной строки, автоматический маршрут,
размер окна 920×680. Внешнее оборудование и запись данных не задействованы.
Рабочий стол заблокирован: ручной прогон мышью не выполнен, изображения получены
через DrawToBitmap из настоящих контролов приложения.

Для повторной сборки используйте Visual Studio / MSBuild с targeting pack .NET 4.8:

```powershell
msbuild prototypes/MultiKKT.AntdPreview/MultiKKT.AntdPreview.csproj /restore /p:Configuration=Release
```

Для самопроверки и сохранения изображений:

```powershell
& ./prototypes/MultiKKT.AntdPreview/bin/Release/net48/MultiKKT.UI-Preview.exe --capture C:/Temp/MultiKKT-Preview
```

Обнаруженные проблемы интерфейса сообщайте с названием примера и размером окна
в [Issues проекта](https://github.com/jadieify-hub/esm-tspiot-multi-kkt-tool/issues).
Этот прототип локальный, в GitHub Releases не опубликован.
