# v11.1

## Что изменилось

- Добавлено последовательное ручное подключение второй, третьей, четвертой и следующих ККТ.
- На вкладке ручного подключения показываются уже созданные экземпляры ЕСМ, их `port`, `softPort` и состояние службы.
- Свободные пары портов назначаются безопасно и последовательно; пара первой ККТ `50401/51401` зарезервирована.
- Автоматический режим повторяет временные сетевые сбои, продолжает работу после ошибки одной ККТ и не расходует порты на некорректные строки.
- Усилены проверки аварийного PowerShell-сценария, удаления дополнительных экземпляров и завершения фоновых операций.
- Экранный журнал ограничен по размеру, а полный журнал сохраняется в файл.
- Стартовая высота главного окна увеличена: нижняя таблица полностью видна при запуске.
- Обновлены название проекта, инструкция, сведения об авторе и владельце.

## Стандартная сборка

- `MultiKKT-ESM-TSPioT-v11.1.exe` — компактный AnyCPU EXE для .NET Framework 4.8 и Windows 7 SP1–11.

Автономные Modern-сборки размером около 60 МБ в этот релиз не входят и подготавливаются отдельно только по запросу.

## Проверка

- 72 shared-теста пройдены в .NET 8 через GitHub Actions.
- Те же 72 shared-теста пройдены системным компилятором и рантаймом .NET Framework.
- Компактный EXE собран с внутренней версией `11.1.0.0`, запущен и проверен на Windows 11.
- PDF-инструкция отрисована и просмотрена на всех 10 страницах.
- Для всех опубликованных файлов рассчитаны контрольные суммы SHA-256.
